วิวและเทมเพลต (views x templates)

อ้างอิง GitHub: บรานช์ 04-views-templates · ส่วนที่เปลี่ยนจากบทก่อนหน้า

วัตถุประสงค์

เมื่อจบบทนี้ ผู้เรียนลงทะเบียนแอปในโปรเจกต์ สร้างเทมเพลต (Template) เป็นไฟล์ HTML และเปลี่ยนวิวให้ส่งเทมเพลตกลับไปแสดงผลได้ แทนการส่งข้อความโดยตรงแบบบทที่ 3

ขั้นตอนที่ 1 ทำความเข้าใจเทมเพลต

เทมเพลตคือไฟล์ที่เก็บโครงหน้าเว็บ ในที่นี้เขียนด้วย HTML ซึ่งเป็นภาษาที่ใช้บอกเบราว์เซอร์ว่าหน้าเว็บมีส่วนประกอบอะไรบ้าง การแยกหน้าเว็บออกเป็นไฟล์เทมเพลตทำให้วิวไม่ต้องเขียน HTML จำนวนมากเป็นข้อความในโค้ด Python วิวเพียงเรียกฟังก์ชัน render เพื่อให้ Django นำเทมเพลตมาสร้างการตอบกลับ

ขั้นตอนที่ 2 ลงทะเบียนแอปในโปรเจกต์

Django ค้นหาไฟล์เทมเพลตในโฟลเดอร์ templates ของแต่ละแอปที่ลงทะเบียนไว้เท่านั้น จึงต้องลงทะเบียนแอปก่อน เปิดไฟล์ project_jrd/settings.py หา INSTALLED_APPS แล้วเพิ่ม 2 บรรทัดท้ายรายการ (ต่อจาก 'django.contrib.staticfiles',)

โค้ด / คำสั่งคำอธิบาย
INSTALLED_APPSรายการแอปที่เปิดใช้งานในโปรเจกต์นี้ แอปที่มากับ Django (django.contrib...) มีอยู่แล้ว
'app_general.apps.AppGeneralConfig'เส้นทางแบบจุดไปยังคลาส AppGeneralConfig ในไฟล์ apps.py ของแอป app_general ซึ่งเห็นในบทที่ 2
'app_foods.apps.AppFoodsConfig'เช่นเดียวกัน สำหรับแอป app_foods

เหตุที่ Django หาเทมเพลตในแอปได้ เพราะใน settings.py ส่วน TEMPLATES มีค่า 'APP_DIRS': True ซึ่งสั่งให้ค้นหาเทมเพลตในโฟลเดอร์ templates ของแต่ละแอปที่ลงทะเบียน

ขั้นตอนที่ 3 สร้างโฟลเดอร์ของเทมเพลต

สร้างโฟลเดอร์ซ้อนกันตามนี้ (ชื่อ templates ต้องสะกดตามนี้ และโฟลเดอร์ชั้นในใช้ชื่อเดียวกับแอป)

  • app_general/templates/app_general/
  • app_foods/templates/app_foods/

Django รวมโฟลเดอร์ templates ของทุกแอปเป็นที่ค้นหาเดียวกัน หากสองแอปมีไฟล์ชื่อ home.html เหมือนกัน Django จะเลือกไฟล์แรกที่พบ การใส่โฟลเดอร์ชั้นในที่ชื่อเดียวกับแอป ทำให้ชื่อไฟล์เต็มไม่ซ้ำกัน เช่น app_general/home.html

ขั้นตอนที่ 4 สร้างเทมเพลตของ app_general

ไฟล์ home.html

ส่วนของโค้ดคำอธิบาย
<!DOCTYPE html>บอกเบราว์เซอร์ว่าเอกสารนี้เป็น HTML
<html lang="en"> ... </html>แท็กครอบเอกสารทั้งหมด คุณสมบัติ lang ระบุภาษาของเอกสาร
<head> ... </head>ส่วนข้อมูลของหน้าเว็บที่ไม่แสดงในเนื้อหา
<meta charset="UTF-8">กำหนดการเข้ารหัสตัวอักษรเป็น UTF-8 เพื่อให้แสดงภาษาไทยถูกต้อง
<meta http-equiv=... > และ <meta name="viewport" ...>เมตา (Meta) ที่ระบุการทำงานร่วมกับเบราว์เซอร์ Internet Explorer และการปรับขนาดหน้าเว็บให้พอดีกับหน้าจอ ไม่มีผลต่อเนื้อหาในบทนี้
<title>ข้อความที่แสดงบนแท็บของเบราว์เซอร์
<body> ... </body>ส่วนเนื้อหาที่แสดงบนหน้าเว็บ
<header>, <footer>ส่วนหัวและส่วนท้ายของหน้า คุณสมบัติ class ตั้งชื่อกลุ่มไว้อ้างอิงภายหลัง และ style กำหนดสีพื้นหลังเป็น lightgray
<a href="/foods">ลิงก์ (Link) ไปยังที่อยู่ที่ระบุใน href โดยข้อความระหว่างแท็กเปิดและปิดคือสิ่งที่ผู้ใช้เห็น
<h1>, <h4>, <p>หัวข้อขนาดใหญ่ หัวข้อขนาดเล็ก และย่อหน้าตามลำดับ

ขั้นตอนที่ 7 เปิดเซิร์ฟเวอร์และทดสอบ

ถ้าเซิร์ฟเวอร์จากบทที่ 3 ยังเปิดอยู่ เซิร์ฟเวอร์จะโหลดโค้ดใหม่เองเมื่อบันทึกไฟล์ .py หากไม่เห็นการเปลี่ยนแปลง ให้หยุดเซิร์ฟเวอร์ด้วย Ctrl และ C แล้วเปิดใหม่
