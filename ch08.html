บทที่ 8 จาก 15

โมเดล (models)

อ้างอิง GitHub: บรานช์ 08-models · ส่วนที่เปลี่ยนจากบทก่อนหน้า

วัตถุประสงค์

เมื่อจบบทนี้ ผู้เรียนสร้างความสัมพันธ์แบบหลายต่อหลาย (Many-to-Many) ระหว่างผู้ลงทะเบียนกับเมนู และใช้ชุดคำสั่งของโมเดลใน Django Shell เพื่อเพิ่ม ค้นหา แก้ไข และลบข้อมูลในฐานข้อมูลได้ ข้อมูลเมนู 5 รายการที่สร้างในบทนี้จะใช้แสดงผลในบทที่ 9

ขั้นตอนที่ 1 เพิ่มความสัมพันธ์ระหว่างโมเดล

ผู้ลงทะเบียนหนึ่งคนเลือกเมนูที่สนใจได้หลายเมนู และเมนูหนึ่งมีผู้สนใจได้หลายคน ความสัมพันธ์แบบนี้เรียกว่า Many-to-Many เปิดไฟล์ app_general/models.py แล้วเพิ่มบรรทัดสุดท้ายในคลาส Subscription

โค้ด / คำสั่งคำอธิบาย
models.ManyToManyField('app_foods.Food')ฟิลด์ความสัมพันธ์แบบหลายต่อหลายไปยังโมเดล Food ของแอป app_foods ระบุเป็นข้อความ 'ชื่อแอป.ชื่อโมเดล' เพราะโมเดลอยู่คนละแอป
food_setชื่อฟิลด์ ใช้เข้าถึงเมนูทั้งหมดที่ผู้ลงทะเบียนคนนั้นเลือก

ฟิลด์นี้ไม่ได้เพิ่มคอลัมน์ในตาราง app_general_subscription แต่ Django สร้างตารางกลางอีกหนึ่งตาราง เพื่อเก็บคู่ของผู้ลงทะเบียนกับเมนู

ขั้นตอนที่ 2 สร้างและใช้ไมเกรชัน

ตารางกลางที่ได้ชื่อ app_general_subscription_food_set มีคอลัมน์ subscription_id และ food_id ซึ่งเก็บ id ของผู้ลงทะเบียนและของเมนูตามลำดับ

ขั้นตอนที่ 3 เปิด Django Shell

คำสั่งนี้เปิดโปรแกรมโต้ตอบของ Python (Shell) ที่โหลดการตั้งค่าของโปรเจกต์แล้ว จึงเรียกใช้โมเดลและเชื่อมต่อฐานข้อมูลได้ ตัวอย่างในขั้นตอนต่อไปแสดงบรรทัดที่ผู้เรียนพิมพ์โดยขึ้นต้นด้วย >>> ส่วนบรรทัดถัดไปที่ไม่มี >>> คือผลที่ Shell แสดง พิมพ์เฉพาะส่วนหลัง >>> แล้วกด Enter ทีละบรรทัด และออกจาก Shell ด้วย exit()

ขั้นตอนที่ 4 นำโมเดลเข้ามาและเพิ่มข้อมูล

โค้ด / คำสั่งคำอธิบาย
from app_foods.models import Foodนำโมเดลเข้ามาใช้ Shell ไม่นำเข้าให้เอง
Food.objectsเมเนเจอร์ (Manager) ของโมเดล ใช้ทำงานกับตารางทั้งตาราง Django เพิ่มให้ทุกโมเดลโดยอัตโนมัติ
Food.objects.all()ดึงข้อมูลทุกแถว ผลเป็น QuerySet ซึ่งเป็นกลุ่มของออบเจกต์โมเดล ตอนนี้ว่างเปล่า
food1 = Food(title='Red Spicy', price=2990)สร้างออบเจกต์ Food ในหน่วยความจำ ยังไม่ถูกบันทึกในฐานข้อมูล
food1.save()บันทึกลงฐานข้อมูล Django ใส่ id ให้ ซึ่งเรียกดูได้ด้วย food1.id
Food.objects.create(...)สร้างและบันทึกในคำสั่งเดียว ผลที่ Shell แสดงคือออบเจกต์ที่สร้าง
<Food: Food object (1)>รูปแบบการแสดงออบเจกต์ตามค่าเริ่มต้น คือชื่อโมเดลและ id ซึ่งไม่สื่อความหมาย บทที่ 11 จะเปลี่ยนให้แสดงชื่อเมนู

เมนูที่สร้างทั้ง 5 รายการ ได้แก่ Red Spicy, Blue Glacier, Yellow Sunrise (มีราคาพิเศษ 2490), Dark Choco Premium และ White Choco Premium (สองรายการหลังเป็นเมนูพิเศษ) การระบุ description='...' ใน create คือคีย์เวิร์ดอาร์กิวเมนต์ (Keyword Argument) ซึ่งกำหนดค่าให้ฟิลด์ตามชื่อ ฟิลด์ที่ไม่ระบุจะได้ค่าเริ่มต้น (null หรือ default)

ขั้นตอนที่ 5 ค้นหาข้อมูล

โค้ด / คำสั่งคำอธิบาย
Food.objects.count()นับจำนวนแถว
Food.objects.get(id=1)ดึงแถวเดียวที่ id เท่ากับ 1 ถ้าไม่พบ จะเกิดข้อผิดพลาด Food.DoesNotExist ถ้าพบมากกว่าหนึ่งแถวจะเกิดข้อผิดพลาด MultipleObjectsReturned
.titleเข้าถึงค่าฟิลด์ของออบเจกต์
Food.objects.filter(is_premium=True)คัดเฉพาะแถวที่เงื่อนไขเป็นจริง
price__gte=3000เงื่อนไขแบบมีส่วนต่อท้ายหลังเครื่องหมาย __ คือ Field Lookup โดย gte หมายถึง มากกว่าหรือเท่ากับ (greater than or equal)
title__icontains='choco'icontains หมายถึง มีข้อความนี้อยู่ในฟิลด์ โดยไม่สนตัวพิมพ์เล็กพิมพ์ใหญ่
Food.objects.exclude(is_premium=True)ตรงข้ามกับ filter คือตัดแถวที่ตรงเงื่อนไขออก
order_by('-price', 'title')เรียงลำดับ เครื่องหมาย - นำหน้าหมายถึงเรียงจากมากไปน้อย ถ้าราคาเท่ากันให้เรียงตาม title

ขั้นตอนที่ 6 แก้ไขและลบข้อมูล

โค้ด / คำสั่งคำอธิบาย
food1.description = '...'เปลี่ยนค่าฟิลด์ในหน่วยความจำ
food1.save()บันทึกการเปลี่ยนแปลงลงฐานข้อมูล ออบเจกต์ที่มี id อยู่แล้วจะถูกแก้ไขแถวเดิม
Food.objects.filter(id=3).update(...)แก้หลายฟิลด์ของทุกแถวที่ตรงเงื่อนไขในคำสั่งเดียว ผลคือจำนวนแถวที่แก้ (1) ในที่นี้ตั้งราคาพิเศษและวันสิ้นสุดโปรโมชั่นเป็น 30 วันนับจากเวลาปัจจุบัน
timezone.now() + timedelta(days=30)timezone.now() คือเวลาปัจจุบัน และ timedelta(days=30) คือช่วงเวลา 30 วัน
temp.delete()ลบแถวนั้นออกจากฐานข้อมูล ผลคือจำนวนแถวที่ลบและรายละเอียดแยกตามโมเดล

ขั้นตอนที่ 7 ใช้ความสัมพันธ์แบบหลายต่อหลาย

โค้ด / คำสั่งคำอธิบาย
Subscription.objects.create(name=..., email=...)สร้างผู้ลงทะเบียน ฟิลด์ status ได้ค่าเริ่มต้น 'unapproved'
somchai.food_set.add(a, b)เพิ่มเมนู 2 รายการให้ผู้ลงทะเบียน (บันทึกลงตารางกลาง)
somchai.food_set.all()ดึงเมนูทั้งหมดที่ผู้ลงทะเบียนคนนี้เลือก ถ้าไม่ใช้ order_by ลำดับของผลลัพธ์ไม่แน่นอน
Food.objects.get(id=1).subscription_set.all()ทิศทางกลับกัน: ดึงผู้ลงทะเบียนทั้งหมดที่เลือกเมนูนี้ Django สร้างชื่อ subscription_set ให้อัตโนมัติจากชื่อโมเดลที่มีฟิลด์ความสัมพันธ์
somchai.delete()ลบผู้ลงทะเบียนพร้อมแถวในตารางกลาง ไม่ลบเมนู
