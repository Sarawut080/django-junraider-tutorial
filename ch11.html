บทที่ 11 จาก 15

หน้าผู้ดูแลระบบ (admin)

อ้างอิง GitHub: บรานช์ 11-admin · ส่วนที่เปลี่ยนจากบทก่อนหน้า

วัตถุประสงค์

เมื่อจบบทนี้ ผู้เรียนสร้างบัญชีผู้ดูแลระบบ เข้าสู่หน้าผู้ดูแลระบบ (Admin) ของ Django และลงทะเบียนโมเดลเพื่อดู ค้นหา กรอง เพิ่ม แก้ไข และลบข้อมูลเมนูและผู้ลงทะเบียนผ่านหน้าเว็บได้

ขั้นตอนที่ 1 ทำความเข้าใจหน้าผู้ดูแลระบบ

ตามเอกสารของ Django หน้าผู้ดูแลระบบ (Admin Site) คือหน้าเว็บสำหรับจัดการข้อมูลที่ Django สร้างให้จากโมเดลโดยอัตโนมัติ โปรเจกต์มีเส้นทาง admin/ และแอป django.contrib.admin ตั้งแต่บทที่ 1 แล้ว สิ่งที่ต้องทำคือสร้างบัญชีผู้ดูแลและลงทะเบียนโมเดลที่ต้องการ

ขั้นตอนที่ 2 สร้างบัญชีผู้ดูแลระบบ

คำสั่งนี้ถามข้อมูลทีละบรรทัดในเทอร์มินัล ดังตาราง ป้ายคำถามบางบรรทัดเป็นภาษาไทยเพราะตั้ง LANGUAGE_CODE = 'th' ไว้ในบทที่ 6

ข้อความที่เทอร์มินัลถามสิ่งที่ต้องทำ
ชื่อผู้ใช้ (leave blank to use '...'):พิมพ์ชื่อผู้ใช้ที่ใช้เข้าสู่ระบบ เช่น admin ถ้ากด Enter โดยไม่พิมพ์ จะใช้ชื่อในวงเล็บ
ที่อยู่อีเมล:พิมพ์อีเมล หรือกด Enter เพื่อเว้นว่าง
Password:พิมพ์รหัสผ่าน ขณะพิมพ์เทอร์มินัลจะไม่แสดงตัวอักษร
Password (again):พิมพ์รหัสผ่านเดิมอีกครั้ง
Bypass password validation and create user anyway? [y/N]:ขึ้นเฉพาะเมื่อรหัสผ่านไม่ผ่านเกณฑ์ เช่น This password is too short. หรือ This password is too common. ให้พิมพ์ N แล้วตั้งรหัสผ่านใหม่ที่ยาวอย่างน้อย 8 ตัวอักษรและคาดเดาได้ยาก

ผู้ใช้ประเภท Superuser มีสิทธิ์จัดการข้อมูลทุกอย่างในหน้าผู้ดูแลระบบ

ขั้นตอนที่ 3 ปรับโมเดลให้ใช้กับหน้าผู้ดูแลระบบ

แทนที่เนื้อหาทั้งไฟล์ app_foods/models.py ด้วยโค้ดนี้ (ส่วนที่เปลี่ยนคือเพิ่ม blank=True ในสามฟิลด์ และเพิ่มเมธอด __str__)

โค้ด / คำสั่งคำอธิบาย
blank=Trueอนุญาตให้เว้นว่างได้ในฟอร์ม ต่างจาก null=True ที่อนุญาตให้ฐานข้อมูลเก็บค่า NULL ตามเอกสารของ Django null เกี่ยวกับฐานข้อมูล ส่วน blank เกี่ยวกับการตรวจสอบในฟอร์ม หากไม่ใส่ blank=True หน้าผู้ดูแลระบบจะบังคับให้กรอกช่องนั้น
def __str__(self) -> str:เมธอดพิเศษของคลาส Python ที่กำหนดข้อความแทนออบเจกต์ ใช้แสดงชื่อรายการในหน้าผู้ดูแลระบบและใน Shell แทน Food object (1)
'{} (id: {})'.format(self.title, self.id)สร้างข้อความโดยแทน {} ด้วยค่า self.title และ self.id ตามลำดับ ได้รูปแบบ เช่น Red Spicy (id: 1)

แทนที่เนื้อหาทั้งไฟล์ app_general/models.py ด้วยโค้ดนี้ (ส่วนที่เปลี่ยนคือเพิ่มเมธอด __str__ ท้ายคลาส Subscription)

ขั้นตอนที่ 4 สร้างไมเกรชันของการเปลี่ยน blank

แม้ blank=True ไม่เปลี่ยนตารางในฐานข้อมูล Django ก็ยังสร้างไมเกรชันเพื่อบันทึกการเปลี่ยนแปลงของโมเดล ส่วน __str__ ไม่ต้องทำไมเกรชัน

ขั้นตอนที่ 5 ลงทะเบียนโมเดลในหน้าผู้ดูแลระบบ

แทนที่เนื้อหาของ app_foods/admin.py และ app_general/admin.py ด้วยโค้ดต่อไปนี้

โค้ด / คำสั่งคำอธิบาย
from app_foods.models import Foodนำโมเดลเข้ามาเพื่อลงทะเบียน
class FoodAdmin(admin.ModelAdmin):คลาสที่กำหนดการแสดงผลของโมเดลในหน้าผู้ดูแลระบบ สืบทอดจาก admin.ModelAdmin
list_display = [...]รายการฟิลด์ที่แสดงเป็นคอลัมน์ในหน้ารายการ
search_fields = ['title']ฟิลด์ที่ค้นหาได้ ทำให้มีช่องค้นหาในหน้ารายการ
list_filter = ['is_premium']ฟิลด์ที่ใช้กรอง ทำให้มีแถบตัวกรองด้านขวา
admin.site.register(Food, FoodAdmin)ลงทะเบียนโมเดล Food กับหน้าผู้ดูแลระบบ โดยใช้การตั้งค่าจาก FoodAdmin
class SubscriptionAdminทำเช่นเดียวกันกับโมเดล Subscription ซึ่งตัวกรองใช้ฟิลด์ status

ขั้นตอนที่ 6 เปิดเซิร์ฟเวอร์และใช้งานหน้าผู้ดูแลระบบ

  • เปิด http://127.0.0.1:8000/admin/ หน้าเข้าสู่ระบบมีช่อง ชื่อผู้ใช้ และ รหัสผ่าน ให้กรอกค่าที่สร้างในขั้นตอนที่ 2 แล้วกดปุ่ม เข้าสู่ระบบ
  • หน้า การจัดการไซต์ มีหัวข้อแอป App_Foods (รายการ Foods) และ App_General (รายการ Subscriptions) รวมกับหัวข้อ การตรวจสอบและอนุมัติ ที่มากับ Django
  • คลิก Foods เพื่อดูรายการเมนู พิมพ์ choco ในช่องด้านบนแล้วกดปุ่ม ค้นหา และเลือกตัวกรองทางขวา (หัวข้อ ตัวกรอง > โดย is premium > ใช่ หรือ ไม่ใช่)
  • คลิกชื่อเมนูหนึ่งรายการเพื่อแก้ไขข้อมูล แล้วกดปุ่ม บันทึก
  • ปุ่ม เพิ่ม food ที่มุมขวาบนของหน้ารายการใช้เพิ่มเมนูใหม่ และปุ่ม ลบ ในหน้าแก้ไขใช้ลบเมนู

ผลลัพธ์ที่ควรได้

  • เข้าสู่ระบบสำเร็จและเห็นหน้า การจัดการไซต์ ของ Django
  • หน้ารายการ Foods มีคอลัมน์ Title, Price, Special price, Is premium, Promotion end at และเมนูทั้ง 5 รายการ
  • ค้นหา choco เหลือ Dark Choco Premium และ White Choco Premium
  • หน้าแก้ไขเมนูแสดงชื่อในรูปแบบ ชื่อ (id: ตัวเลข) เช่น Red Spicy (id: 1) ตามเมธอด __str__
  • แก้ไขเมนูแล้วบันทึกได้โดยไม่ต้องกรอกช่องที่ตั้ง blank=True (Special price, Promotion end at, Description)
  • หน้าเว็บบทที่ 9 (เช่น /foods/) แสดงข้อมูลที่แก้ในหน้าผู้ดูแลระบบทันที
