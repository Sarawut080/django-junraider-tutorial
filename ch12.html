ไฟล์ภาพสแตติก (static images)

อ้างอิง GitHub: บรานช์ 12-static-images · ส่วนที่เปลี่ยนจากบทก่อนหน้า

วัตถุประสงค์

เมื่อจบบทนี้ ผู้เรียนนำไฟล์ภาพที่เป็นสแตติกไฟล์ (Static Files) เข้าโปรเจกต์ เก็บที่อยู่ภาพของเมนูในฐานข้อมูล และแสดงภาพบนหน้าเว็บด้วยแท็ก static ได้

ขั้นตอนที่ 1 ทำความเข้าใจสแตติกไฟล์

สแตติกไฟล์ (Static Files) คือไฟล์ที่ Django ส่งให้เบราว์เซอร์ตามที่เก็บไว้โดยไม่ประมวลผล ได้แก่ ภาพ ไฟล์ CSS และไฟล์ JavaScript ตามเอกสารของ Django แอป django.contrib.staticfiles (มีใน INSTALLED_APPS ตั้งแต่บทที่ 1) ค้นหาไฟล์เหล่านี้ในโฟลเดอร์ static ของแต่ละแอป และค่า STATIC_URL = 'static/' ใน settings.py คือส่วนต้นของที่อยู่ที่ใช้เรียกไฟล์ เช่น ไฟล์ app_general/logo.png เรียกที่ /static/app_general/logo.png ระหว่างพัฒนา runserver ส่งไฟล์เหล่านี้ให้โดยอัตโนมัติ

การตั้งชื่อโฟลเดอร์ใช้หลักเดียวกับเทมเพลตในบทที่ 4 คือ app_ชื่อแอป/static/app_ชื่อแอป/ เพื่อไม่ให้ชื่อไฟล์ซ้ำกันข้ามแอป

ขั้นตอนที่ 2 นำไฟล์ภาพจาก GitHub เข้าโปรเจกต์

ภาพทั้งหมดเตรียมไว้แล้วในรีโพสิตอรี django-junraider บน GitHub ดาวน์โหลดโฟลเดอร์ของบรานช์นี้เป็นไฟล์ ZIP (ไฟล์บีบอัดที่รวมหลายไฟล์ไว้ในไฟล์เดียว) แล้วแตกไฟล์ (Extract)

จากนั้นคัดลอกโฟลเดอร์ 2 โฟลเดอร์ในไฟล์ที่แตกออกมาไปไว้ในโปรเจกต์ โดยคัดลอกทั้งโฟลเดอร์ static

  • จาก app_foods/static/ ไปที่ app_foods/ ของโปรเจกต์ (ภาพเมนู 5 ภาพ)
  • จาก app_general/static/ ไปที่ app_general/ ของโปรเจกต์ (ไฟล์ favicon.ico, logo.png, home-about-1.jpg, home-about-2.jpg, home-about-3.jpg, home-bg.jpg)

ดูรายการไฟล์ในรีโพสิตอรีได้ที่ app_foods/static/app_foods และ app_general/static/app_general

ภาพอาหารมาจากเว็บ Unsplash และไอคอน logo.png มาจาก Iconfinder ตามรายการอ้างอิงในหน้า ที่มา (Credits)

ขั้นตอนที่ 3 เพิ่มฟิลด์เก็บที่อยู่ภาพในโมเดล Food

แทนที่เนื้อหาทั้งไฟล์ app_foods/models.py ด้วยโค้ดนี้ (ส่วนที่เปลี่ยนคือเพิ่มฟิลด์ image_relative_url ต่อจากฟิลด์ description)

โค้ด / คำสั่งคำอธิบาย
image_relative_url = models.CharField(max_length=50, null=True, blank=True)ฟิลด์ข้อความที่เก็บเส้นทางของไฟล์ภาพเทียบจากโฟลเดอร์ static เช่น app_foods/food-red-spicy.jpg ฐานข้อมูลเก็บเพียงข้อความนี้ ไม่เก็บไฟล์ภาพ

บันทึกการเปลี่ยนแปลงของโมเดลลงฐานข้อมูลด้วยไมเกรชันเหมือนบทที่ 11 คำสั่งแรกสร้างไฟล์ไมเกรชันที่เพิ่มคอลัมน์ image_relative_url คำสั่งที่สองเพิ่มคอลัมน์นี้ในตาราง app_foods_food

ขั้นตอนที่ 5 แสดงภาพในเทมเพลต

แทนที่เนื้อหาทั้งไฟล์ของเทมเพลต 6 ไฟล์ด้วยโค้ดต่อไปนี้ เริ่มจากเทมเพลตฐานและส่วนหัว

โค้ด / คำสั่งคำอธิบาย
{% load static %}โหลดชุดแท็กของสแตติกไฟล์เข้าเทมเพลตนี้ ต้องเขียนก่อนใช้แท็ก static ในทุกไฟล์ที่ใช้ และต้องอยู่หลังแท็ก {% extends %} ในเทมเพลตที่สืบทอด
{% static 'app_general/logo.png' %}แท็ก static สร้างที่อยู่ของไฟล์จากค่า STATIC_URL ได้ /static/app_general/logo.png
<link rel="icon" href="...">กำหนดไอคอนของแท็บเบราว์เซอร์ (Favicon)
<img src="...">แท็ก HTML แสดงภาพจากที่อยู่ใน src

หน้าแรก

หน้ารายการเมนูและหน้ารายละเอียดเมนู ใช้ค่า food.image_relative_url จากฐานข้อมูลเป็นพารามิเตอร์ของแท็ก static

โค้ด / คำสั่งคำอธิบาย
{% static food.image_relative_url %}พารามิเตอร์ของ static เป็นตัวแปรได้ ไม่จำกัดเฉพาะข้อความ ภาพของแต่ละเมนูจึงต่างกันตามข้อมูลในฐานข้อมูล
<a href="{% url 'food' food.id %}" style="display: block;"><img ...></a>ทำให้ภาพเป็นลิงก์ไปหน้ารายละเอียดเมนู display: block ทำให้ลิงก์แสดงเต็มความกว้างของบรรทัด
