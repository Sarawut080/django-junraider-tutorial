ไฟล์ CSS และ JavaScript สแตติก

อ้างอิง GitHub: บรานช์ 13-static-css-js · ส่วนที่เปลี่ยนจากบทก่อนหน้า

วัตถุประสงค์

เมื่อจบบทนี้ ผู้เรียนจัดรูปแบบหน้าเว็บด้วยไฟล์ CSS เพิ่มฟอนต์ภาษาไทย และเพิ่มการตรวจสอบฟอร์มด้วยไฟล์ JavaScript ซึ่งทั้งหมดเป็นสแตติกไฟล์ที่เรียกใช้ผ่านแท็ก static ได้ และปรับเทมเพลตทุกหน้าให้ใช้ชื่อคลาส (Class) ของ CSS

ขั้นตอนที่ 1 ทำความเข้าใจ CSS และ JavaScript

  • CSS (Cascading Style Sheets) คือภาษาที่กำหนดรูปแบบการแสดงผลของ HTML เช่น สี ขนาดตัวอักษร และการจัดวาง แต่ละกฎประกอบด้วยซีเล็กเตอร์ (Selector) ที่ระบุว่าใช้กับส่วนใดของหน้า และชุดคุณสมบัติ (Property) ที่ระบุรูปแบบ เช่น h1 { font-size: 32px; } ซีเล็กเตอร์ที่ขึ้นต้นด้วยจุด เช่น .button หมายถึงองค์ประกอบ HTML ที่มี class="button"
  • JavaScript คือภาษาโปรแกรมที่ทำงานในเบราว์เซอร์ ใช้ทำให้หน้าเว็บตอบสนองต่อผู้ใช้ เช่น ตรวจสอบฟอร์มก่อนส่ง
  • ไฟล์ทั้งสองชนิดเป็นสแตติกไฟล์ ตามที่อธิบายในบทที่ 12

ขั้นตอนที่ 2 นำไฟล์ฟอนต์และ normalize.css จาก GitHub เข้าโปรเจกต์

ดาวน์โหลดโฟลเดอร์ของบรานช์นี้เป็นไฟล์ ZIP แล้วแตกไฟล์

คัดลอกไฟล์และโฟลเดอร์ต่อไปนี้จาก app_general/static/app_general/ ในไฟล์ที่แตกออกมา ไปไว้ใน app_general/static/app_general/ ของโปรเจกต์

  • โฟลเดอร์ fonts ซึ่งเก็บไฟล์ฟอนต์ Mitr (ฟอนต์ภาษาไทยและละติน) หลายรูปแบบไฟล์ เพื่อให้เบราว์เซอร์แต่ละชนิดเลือกใช้
  • ไฟล์ normalize.css เป็นไฟล์ CSS ของบุคคลที่สามที่ช่วยให้เบราว์เซอร์ต่าง ๆ แสดงองค์ประกอบ HTML พื้นฐานได้ใกล้เคียงกัน (ส่วนหัวไฟล์ระบุ normalize.css v8.0.1 สัญญา MIT) ไม่ต้องแก้ไขไฟล์นี้
  • ไฟล์ main.css (อธิบายในขั้นตอนที่ 3)
  • ไฟล์ home-bg.jpg ให้เขียนทับไฟล์เดิม เพราะบรานช์นี้เปลี่ยนภาพพื้นหลังหน้าแรก

ไฟล์ main.css มีเนื้อหายาว จึงคัดลอกแทนการพิมพ์ ส่วน main.js ในขั้นตอนที่ 4 สั้น ให้พิมพ์ตามโค้ด ดูไฟล์ในรีโพสิตอรีที่ app_general/static/app_general

คำอธิบายแยกตามส่วนของไฟล์

ส่วนของไฟล์คำอธิบาย
@font-face { font-family: 'Mitr'; ... }กำหนดฟอนต์ที่เบราว์เซอร์ต้องดาวน์โหลดมาใช้ โดย src: url('fonts/...') ระบุที่อยู่ไฟล์ฟอนต์เทียบจากไฟล์ CSS นี้ มี 2 น้ำหนัก คือ 300 (บาง) และ 400 (ปกติ)
*, ::before, ::after { box-sizing: border-box; }ให้ความกว้างและความสูงขององค์ประกอบนับรวมแพดดิง (Padding) และเส้นขอบ ทำให้คำนวณขนาดง่ายขึ้น
html { color; font-family: 'Mitr', sans-serif; font-weight: 300; }กำหนดสีตัวอักษรและฟอนต์พื้นฐานทั้งหน้า ถ้าเบราว์เซอร์ไม่มีฟอนต์ Mitr จะใช้ฟอนต์ sans-serif ของระบบแทน
h1 ... h6, p, aกำหนดขนาดตัวอักษร ระยะห่างบรรทัด (line-height) ระยะขอบล่าง (margin-bottom) ของหัวข้อ ย่อหน้า และสีลิงก์
.text-gray, .text-center, .image-blockคลาสใช้ซ้ำสำหรับสีเทา การจัดกึ่งกลางข้อความ และภาพที่แสดงเป็นบล็อกและไม่กว้างเกินพื้นที่ (max-width: 100%)
.content-section, .content-containerกำหนดระยะขอบของส่วนเนื้อหาและความกว้างสูงสุด 1200px โดยจัดกึ่งกลางด้วย margin-left/right: auto
.grid, .grid-2, .grid-3จัดวางแบบตาราง (display: grid) เริ่มต้นเป็น 1 คอลัมน์ เมื่อหน้าจอกว้างอย่างน้อย 720px (@media screen and (min-width: 720px)) จึงแบ่งเป็น 2 หรือ 3 คอลัมน์เท่ากัน (1fr 1fr 1fr)
.site-header, .site-header-item, .site-header-brandส่วนหัวของเว็บ จัดเรียงลิงก์ในแนวนอนด้วย display: flex มีเงา (box-shadow) และเปลี่ยนสีพื้นหลังเมื่อเลื่อนเมาส์ไปชี้ (:hover) พร้อมการเปลี่ยนสีอย่างค่อยเป็นค่อยไป (transition)
.site-footer, .site-footer-copyrightส่วนท้ายของเว็บ พื้นหลังสีเทาอ่อน ข้อความกึ่งกลาง
label, input[type='text'], input[type='email'], .form-fieldรูปแบบของฟอร์ม ช่องกรอกมีเส้นขอบ มุมโค้ง (border-radius) และเปลี่ยนสีเส้นขอบเมื่อคลิกอยู่ในช่อง (:focus)
.button, .button-primaryปุ่มและลิงก์ที่ดูเป็นปุ่ม .button-primary เปลี่ยนสีพื้นหลังเป็นสีน้ำเงิน
.home-landing, .home-landing-textส่วนบนสุดของหน้าแรกที่ใช้ภาพ home-bg.jpg เป็นพื้นหลัง (background-image) ขยายให้เต็มพื้นที่ (background-size: cover)
.food-image-link, .food-title a:not(:hover)ลิงก์ภาพเมนูและชื่อเมนู ชื่อเมนูมีสีดำและไม่มีขีดเส้นใต้ ยกเว้นขณะเลื่อนเมาส์ไปชี้

ขั้นตอนที่ 6 ปรับเทมเพลตให้ใช้คลาส CSS

แทนที่เนื้อหาทั้งไฟล์ของเทมเพลตต่อไปนี้ แต่ละไฟล์ใช้ชื่อคลาสที่กำหนดใน main.css และลบรูปแบบ style="..." ที่เขียนไว้ในแท็กโดยตรงออก

ส่วนที่เปลี่ยนคือลบ style ที่กำหนดสีพื้นหลังสีเทา และครอบข้อความของลิงก์ เมนูทั้งหมด และ เกี่ยวกับ ด้วยแท็ก <span>

ส่วนที่เปลี่ยนคือลบ style เปลี่ยนหัวข้อจาก <h4> เป็น <h6> ลบ class ของลิงก์ และเพิ่มคลาส site-footer-copyright ให้ย่อหน้าลิขสิทธิ์

ส่วนที่เปลี่ยนคือส่วนแรก (home-landing) เปลี่ยนข้อความใต้หัวข้อจาก <p> เป็น <h4> และ <h6> และเพิ่มปุ่ม 2 ปุ่ม ส่วนที่สอง (content-section) เปลี่ยนหัวข้อจาก <h2> เป็น <h3> จัดภาพ 3 ภาพเป็น 3 คอลัมน์ด้วย grid grid-3 และเพิ่มปุ่มไปหน้าเกี่ยวกับ

ส่วนที่เปลี่ยนคือครอบเนื้อหาด้วย <section> และ <div class="content-container"> เปลี่ยนหัวข้อหลักเป็น <h3 class="content-title"> และหัวข้อย่อยจาก <h4> เป็น <h5>

ส่วนที่เปลี่ยนคือครอบเนื้อหาด้วย <section> เปลี่ยนหัวข้อจาก <h1> เป็น <h3> ใช้ {% if foods.count > 0 %} แทนแท็ก {% empty %} จัดรายการเป็น 3 คอลัมน์ แสดงราคาพร้อมคำว่า บาท โดยราคาพิเศษอยู่ก่อนราคาเดิม และใช้คลาส text-gray แทน style

ส่วนที่เปลี่ยนคือจัดภาพไว้ซ้ายและรายละเอียดไว้ขวาด้วย grid grid-2 เพิ่มปุ่ม ลงทะเบียนรับโปรโมชั่น และกรณีไม่พบเมนูเปลี่ยนข้อความเป็นหัวข้อ <h3> แล้วเพิ่มคำอธิบายกับปุ่ม กลับไปหน้าเมนูทั้งหมด

ส่วนที่เปลี่ยนคือครอบเนื้อหาด้วย <section> และกล่องแคบ (content-container-narrow) เปลี่ยนหัวข้อจาก <h1> เป็น <h3> เพิ่มย่อหน้าแนะนำ เพิ่มคลาส subscription-form ให้ฟอร์ม ใช้ <div class="form-field"> แทน style และเพิ่มคลาส button button-primary ให้ปุ่ม

ส่วนที่เปลี่ยนคือครอบเนื้อหาด้วย <section> เปลี่ยนหัวข้อจาก <h1> เป็น <h3> และเปลี่ยนลิงก์ กลับหน้าแรก ให้แสดงเป็นปุ่ม
