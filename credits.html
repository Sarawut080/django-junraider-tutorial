โค้ดตัวอย่าง

โค้ดตัวอย่างในสื่อนี้มาจากโปรเจกต์ django-junraider โดย Potchara Puttawanchai เผยแพร่ภายใต้สัญญาอนุญาต MIT

  • รีโพสิตอรี: https://github.com/potchangelo/django-junraider
  • README (รายการบรานช์ของทุกบทและรายการอ้างอิงภาพ): https://github.com/potchangelo/django-junraider#readme
  • บรานช์ของแต่ละบท: ดูตารางในหน้า สารบัญ และลิงก์ที่ด้านบนของแต่ละบท
  • โค้ดสมบูรณ์ของ Season 1: บรานช์ season-1

โค้ดในบทเรียนมาจากบรานช์ 01-setup ถึง 15-deploy-heroku โดยปรับส่วนฐานข้อมูลให้ใช้ PostgreSQL (บทที่ 7 และ 14) และส่วนการนำขึ้นใช้งานจริงให้ใช้ Render (บทที่ 15) คำอธิบายทั้งหมดเขียนขึ้นใหม่

คลิปสอนต้นฉบับ

โปรเจกต์ django-junraider เป็นโค้ดประกอบคลิป สอน Django เบื้องต้น จนใช้ได้จริง ของช่อง Zinglecode (Season 1: youtube.com/watch?v=BBL8W-lpNHw) คลิปเป็นของเจ้าของช่อง สื่อนี้ไม่ได้คัดลอกเนื้อหาจากคลิป

เอกสารอ้างอิงทางเทคนิค

  • Django 4.0: docs.djangoproject.com/en/4.0/ (นิยามและคำอธิบายของแนวคิดต่าง ๆ ตรวจสอบกับเอกสารนี้)
  • Render: render.com/docs/deploy-django, render.com/docs/python-version, render.com/docs/postgresql-creating-connecting
  • PostgreSQL และ pgAdmin: postgresql.org/download, pgadmin.org
  • WhiteNoise: whitenoise.readthedocs.io
