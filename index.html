สื่อการสอน Django แบบทีละขั้น

อ้างอิงโปรเจกต์ django-junraider (Season 1)

อ้างอิง GitHub: https://github.com/potchangelo/django-junraider · โค้ดสมบูรณ์ของ Season 1 (บรานช์ season-1)

เกี่ยวกับสื่อนี้

สื่อนี้อธิบายการสร้างเว็บไซต์ด้วย Django ทีละขั้นตอนสำหรับผู้ที่ไม่มีพื้นฐาน โดยสร้างเว็บไซต์ขายไอศกรีมชื่อ จันทร์ไรเดอร์ ตามโค้ดของโปรเจกต์ django-junraider ใน Season 1 ซึ่งมี 15 บทเรียน แต่ละบทมีโครงเหมือนกัน คือ วัตถุประสงค์ ขั้นตอน ผลลัพธ์ที่ควรได้ และโครงสร้างไฟล์หลังจบบท และมีลิงก์ไปบรานช์ของบทนั้นในรีโพสิตอรีบน GitHub ที่ด้านบนของทุกบท

คำที่พบในทุกบท

  • Git คือโปรแกรมที่บันทึกประวัติการแก้ไขโค้ด ทำให้ย้อนดูหรือย้อนกลับไปยังโค้ดก่อนหน้าได้
  • GitHub คือเว็บไซต์สำหรับเก็บและเผยแพร่โค้ดที่บันทึกด้วย Git
  • รีโพสิตอรี (Repository) คือที่เก็บโค้ดของโปรเจกต์หนึ่งโปรเจกต์บน GitHub
  • บรานช์ (Branch) คือสายการพัฒนาโค้ดแยกกันภายในรีโพสิตอรีเดียว รีโพสิตอรี django-junraider มีบรานช์ 1 บรานช์ต่อ 1 บท เช่น บรานช์ 03-urls-views เก็บโค้ดที่เสร็จหลังจบบทที่ 3 ลิงก์ อ้างอิง GitHub ที่ด้านบนของแต่ละบทและที่หัวกล่องโค้ดจึงเปิดไฟล์ของบรานช์ประจำบทนั้น

เครื่องมือที่ใช้

  • Python 3.10
  • Django 4.0
  • pipenv สำหรับสร้างสภาพแวดล้อมเสมือนและจัดการแพ็กเกจ
  • PostgreSQL เป็นฐานข้อมูล และ pgAdmin สำหรับสร้างและดูฐานข้อมูล (เริ่มใช้ตั้งแต่บทที่ 7)
  • GitHub และ Render สำหรับนำเว็บขึ้นใช้งานจริง (บทที่ 15)
